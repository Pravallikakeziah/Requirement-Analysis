# Requirement-Analysis
This project demonstrates end-to-end requirement analysis and solution design for a Generative AI–powered HR chatbot. The chatbot is intended to answer common employee HR queries such as leave policies, reimbursement processes, holidays, and benefits in a fast, consistent, and scalable manner.

The repository focuses on business requirements documentation (BRD), user stories with acceptance criteria, and a high-level system architecture, showcasing skills in requirement gathering, analytical thinking, and AI product design rather than implementation.
